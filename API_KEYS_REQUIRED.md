# API Keys Required (free-first)

No credential is required to start a deterministic local KAVACH demo. Avoid adding a key unless enabling the matching provider.

| Service | Purpose | Required? | Free path / signup | Environment variable | Fallback |
|---|---|---|---|---|---|
| Open-Meteo | Weather and forecast | No for non-commercial demo | [API docs](https://open-meteo.com/en/docs); free non-commercial access, no key | Existing `WEATHER_API_URL` | Cached last result, then deterministic simulated conditions; label state. Commercial use is not free. |
| OpenStreetMap data | City roads/buildings | No for bundled files | [OpenStreetMap](https://www.openstreetmap.org/); no key | `OSM_DATA_PATH` (optional) | Bundled static extract. ODbL attribution required. |
| CARTO tiles | Existing dark basemap | No key in current style URL | [CARTO basemaps](https://carto.com/basemaps/) | `VITE_BASEMAP_STYLE_URL` (proposed) | Local bundled OSM features over dark background; include attribution. Public services have fair-use limits. |
| Mapzen terrain tiles on AWS Open Data | Terrain mesh | No key | [AWS Terrain Tiles registry](https://registry.opendata.aws/terrain-tiles/) | None | City remains renderable with OSM building extrusions if external DEM tiles are unavailable. |
| data.gov.in | Government datasets when a resource has API access | Optional; needed only for API resources | [Create account/API key](https://data.gov.in/user/register), [API guide](https://data.gov.in/help/how-use-datasets-apis) | `DATAGOV_API_KEY`, resource ID per provider | Download legally reusable dataset; otherwise no connection and mark unavailable. |
| Gemini Live | Optional live speech transcription for KAVACH commands | No key for browser speech; required for Gemini Live | [Gemini Live transcription](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe); usage and quotas depend on account/Google terms | `GEMINI_API_KEY` and optional `GEMINI_LIVE_TRANSCRIBE_MODEL` (backend only) | Browser Web Speech API. Server issues a constrained ephemeral token; key never goes to client. |
| AssemblyAI | Optional streaming speech recognition | Not required for default browser voice; required for AssemblyAI streaming | [Streaming docs](https://www.assemblyai.com/docs/streaming) · check [current pricing](https://www.assemblyai.com/pricing/) and limits | `ASSEMBLYAI_API_KEY` (backend only) | Browser Web Speech API; support depends on browser/OS. |
| n8n webhook | Optional workflow notification target | No key for self-hosted local instance; network URL required | [Self-host n8n](https://docs.n8n.io/hosting/); hosted plans are not a free-forever path | `N8N_WEBHOOK_URL`, `KAVACH_EXTERNAL_ACTIONS_ENABLED` | Local audit event only. External send is disabled by default and demo mode. |
| Bengaluru Open Data Portal | Civic downloads | Usually no API key; resource-specific | [BenSCL DataStore](https://opendata.benscl.com/) | None currently | Bundled city extract/demo inventory. Check each dataset license. |
| Traffic / ambulance / hospital / fire APIs | Operational feeds | No free public Bengaluru API verified | No public free signup link verified | Not configured | Demo data only; no emergency dispatch. |
| OSRM public demo routing | Optional road routing experiment | No key | [OSRM](https://project-osrm.org/) | `ROUTING_PROVIDER_URL` (proposed) | Existing local OSMnx route graph. Public demo server is not production SLA. |
| LLM provider | Optional free-tier agent summaries | Not required; core agents should be deterministic | Provider free quotas/terms vary and can change; there is no durable “free forever” guarantee | `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL` | Deterministic specialists and templates. No key needed for core workflows. |
| SMS (Twilio) | External notifications | Only if sending real SMS | [Twilio trial](https://www.twilio.com/try-twilio); trial has restrictions and may require verification/payment details | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER` | Local event log; no external message sent. |
| WhatsApp Cloud API | WhatsApp notifications | Only if sending | [Meta developer setup](https://developers.facebook.com/docs/whatsapp/cloud-api/get-started); test setup/limits apply, not guaranteed free for ongoing production | `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID` | Local event log; approval required. |
| Email (SMTP) | Email notification | Only if sending | Use an existing account's SMTP; provider rules vary. No free provider selected. | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_FROM` | Local event log. Never put credentials in source. |
| n8n | Workflow automation | No key for self-hosted local use; webhook secret recommended | [Self-host with Docker](https://docs.n8n.io/hosting/); hosted cloud is paid after trial | `N8N_WEBHOOK_URL`, `N8N_WEBHOOK_SECRET` | Local event log. Webhook delivery remains approval-gated. |
| Voice / speech | Gemini Live transcription, AssemblyAI streaming, or browser speech; browser TTS | Gemini/AssemblyAI optional; browser path needs no app key | [Gemini Live docs](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe) | `GEMINI_API_KEY` or `ASSEMBLYAI_API_KEY` in backend only | Typed command input and browser speech. Speaker identity is not verified. |
| Gmail SMTP | Optional explicit approval email to configured test recipients | No key for local demo; Gmail App Password required to send | [Google App Password help](https://support.google.com/accounts/answer/185833) | `KAVACH_EMAIL_ENABLED`, `KAVACH_EMAIL_USER`, `KAVACH_EMAIL_APP_PASSWORD`, and department recipient variables in backend only | Review drafts or simulate send; simulated status explicitly says no email was sent. |
| OCR | Road-report text extraction | No cloud key with local Tesseract.js | [Tesseract.js](https://github.com/naptha/tesseract.js), Apache-2.0 | None | OCR unavailable message if local WASM/model cannot load. OCR is not proof of location. |
| Road damage detector | Pothole/crack classification | No API key for local inference; compatible model file and verified license required | No model with verified compatible license bundled | `ROAD_DAMAGE_MODEL_PATH`, `ROAD_DAMAGE_MODEL_LICENSE` | Detector reports unavailable; no damage prediction is made. |

## Key setup links

- Government API key: [data.gov.in registration](https://data.gov.in/user/register). It is free to register, but an API key does not make every catalog dataset an API.
- Free non-commercial weather: [Open-Meteo](https://open-meteo.com/en/docs). No key; attribution and non-commercial terms apply.
- No-key map data: [OpenStreetMap](https://www.openstreetmap.org/). ODbL attribution/share-alike terms apply.
- Optional speech service: [AssemblyAI streaming docs](https://www.assemblyai.com/docs/streaming). A backend key enables short-lived browser tokens; no key is needed for built-in browser speech.
- Real messaging, operational data, and commercial weather are not guaranteed to be free. For a zero-cost demo use local events, browser speech, and deterministic simulation.
